# HOBS Companion — web files

This repository holds only the public web files of the HOBS Companion app (the same files served
at https://app.homeofbeautifulsouls.com/). Early versions of the Android app load their screens
from this repository's GitHub Pages address, so it has to stay public and keep this exact name.

Nothing else belongs here: no source notes, no server code, no keys. It is updated only when a
production release is made.
